# 새가족부 교재 (모바일)

삼일교회 새가족부 디모데 교재(「그리스도인의 삶」 1~4과)와 여호수아 교재(1~5과)를 휴대폰으로 보는 페이지입니다.
GitHub Pages로 `docs/` 폴더를 서비스합니다.

- `docs/index.html` : 안내 페이지 (두 교재로 이동)
- `docs/timothy.html` : 디모데 교재
- `docs/joshua.html` : 여호수아 교재
- `src/` : 교재 데이터와 생성기

## 교재 내용을 고칠 때

`src/data_timothy.js` 또는 `src/data_joshua.js` 를 수정한 뒤 저장소 루트에서 실행합니다.

    node src/build.js docs

그 다음 커밋·푸시하면 1~2분 뒤 GitHub Pages에 반영됩니다.

## 기능

- 과 탭 전환, 질문별 메모·체크 (기기 브라우저에 저장)
- 글자 크기 조절, 다크 모드
- 여호수아 교재: 성경 구절 칩을 누르면 본문이 펼쳐짐
- 각 과 하단: 메모가 담긴 교재 HTML을 만들어 공유(카카오톡 등)하거나 파일로 저장
